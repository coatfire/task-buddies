# TB-02 Setting up a routine: decisions

- **No account step.** `APP_FACTS.md` confirms there is no account, sign-up, login or email step, so the Question beat contrasts against a sign-up form as the brief describes. The form is drawn in neutral greys, not in app styling, and has no child-name field.
- **One continuous take.** `screens/taskbuddies/video/setup-take.mp4` was recorded from a fresh install in one go: first screen, Set up, parent gate, Parent Area, Done, choose Hoppy, Homework, Edit tasks, parent gate, edit, Save, Done. The film uses it from 0.8 s to the end of the scroll back up, with no cuts.
- **Speed.** Real speed from the first screen through the first parent gate, so the gate is seen plainly: the question, the typed answer, the button. From "Open Parent Area" on, the take plays at x2 with an "x2" tag on screen the whole time. The set-up takes about 33 s of real time; the film makes no time claim.
- **Routine.** The app has no after-school type, so the brief's Homework fallback is used. The Homework defaults were edited through the UI: Reading and Pack Backpack for Tomorrow removed, a custom task added and typed as "Tidy up". The task names on screen are the app's own: Unpack Backpack, Have a Snack, Homework, Tidy up. The film never calls it an after-school routine.
- **Turn.** In the same take: Homework goes from 20 to 25 minutes with the + button (edit one task), then Have a Snack is dragged above Unpack Backpack (reorder another), then Save.
- **Other product kept out.** On first open, the Parent Area shows a Lovou card under "Enable rewards". For the 1.3 s of film (2.6 s of take) the Parent Area is on screen, the take is reframed to the top 29% of the screen (header, title and the rewards switch), shown as a shorter, wider card. The frame boundary was measured from the live page (the card's top edge is at 258 of 844 px; the frame keeps 245 px). Time runs on uninterrupted, so this is a visible reframe, not a cut.
- **Payoff.** "The phone turned round" is the ready screen turning edge-on and back round in brand tokens. No device mock-up, no hand.
- **Child name.** The app never asks for a child's name, so no name field appears.
- **Emoji.** Task emoji are rendered in the Windows emoji font (the capture machine), not Apple's.
- **Sound.** Silent stereo track.
